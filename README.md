Repository description
An introductory PyTorch notebook for MNIST handwritten digit classification, featuring dataset loading, batch visualization, and a custom convolutional neural network architecture.

Features
MNIST training and test dataset loading with automatic download enabled

Image-to-tensor preprocessing

Batched data loading with a batch size of 60

Image-grid visualization using torchvision and Matplotlib

A custom CNN with two convolutional layers

A fully connected output layer configurable by the number of classes

Dependencies
The notebook imports:

-NumPy

-pandas

-Matplotlib

-PyTorch

-torchvision

-torchmetrics

-tqdm
